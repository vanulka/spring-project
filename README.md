# 🛒 Spring Project: Мини-магазин

Приложение представляет собой мини-интернет-магазин, созданный для демонстрации продвинутой конфигурации Spring Boot, работы со скоупами бинов, профилями и жизненным циклом.

## 🚀 Стек технологий
*   **Java 17**
*   **Spring Boot 3**
*   **Spring Security** (Аутентификация, авторизация, роли)
*   **Spring Data JPA / Hibernate** (Работа с БД)
*   **H2 Database** (Файловый режим)
*   **Thymeleaf** (Серверный рендеринг HTML)
*   **Spring Shell** (Консольные команды)
*   **Gradle** (Система сборки)
*   **Lombok** (Генерация шаблонного кода)

## ✨ Реализованные требования
1.  **Git:** Проект версионируется, вся история изменений сохранена.
2.  **Бизнес-объекты:** Реализованы сущности `User` (Пользователь) и `Product` (Товар).
3.  **Авторизация:** Настроена через Spring Security. Разделение ролей `ADMIN` и `USER`. Реализована регистрация новых пользователей.
4.  **Админка:** Полноценный CRUD (Create, Read, Update, Delete) для управления товарами.
5.  **Продвинутая конфигурация Spring (из лекции):**
    *   **Профили:** Используется профиль `dev` для разработки (H2) и заготовка `prod`.
    *   **Скоупы бинов (Bean Scopes):**
        *   `Singleton` — сервисы и репозитории (по умолчанию).
        *   `Session` — корзина пользователя (`ShoppingCart`). Уникальна для каждой сессии.
        *   `Prototype` — генератор чеков (`ReceiptGenerator`). Создается заново при каждом запросе.
    *   **Scoped Proxy:** Session-бин (`ShoppingCart`) успешно внедрен в Singleton-бин (`MainController`) с помощью `proxyMode = ScopedProxyMode.TARGET_CLASS`.
    *   **Жизненный цикл (Lifecycle):** В бине `ShoppingCart` используются аннотации `@PostConstruct` и `@PreDestroy` для логирования создания и уничтожения сессии.
6.  **DTO и Валидация:** Внедрен `UserRegistrationDto` для безопасной передачи данных и валидации при регистрации (проверка на пустые поля, формат email, совпадение паролей).
7.  **Spring Shell:** Реализована консольная команда `list-products` для вывода списка товаров прямо в консоль.

## 🛠️ Инструкция по запуску

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/vanulka/spring-project
    ```
2.  **Запустите приложение:**
    *   Через IntelliJ IDEA: запустите главный класс `OtusSpringProjectApplication`.
    *   Или через терминал, собрав и запустив проект:
        ```bash
        ./gradlew bootRun
        ```
3.  **Откройте браузер:** Перейдите по адресу [http://localhost:8080](http://localhost:8080).

## 🗄️ Подключение к базе данных (DBeaver)
Приложение использует H2 в файловом режиме. Данные сохраняются в папке `data` в корне проекта.
Для подключения через DBeaver используйте следующие настройки:
*   **JDBC URL:** `jdbc:h2:file:./data/otusdb;AUTO_SERVER=TRUE`
*   **Username:** `sa`
*   **Password:** *(оставьте пустым)*

## 🐚 Использование Spring Shell
После запуска приложения в консоли IDE появится приглашение `shell:>`.
Введите команду:
```text
list-products
```
Приложение выведет список всех товаров, находящихся в базе данных, прямо в консоль.
